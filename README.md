# Excel-сборщик отчётов

Собирает папку однотипных таблиц в один сводный отчёт с итогами.

**[Попробовать в браузере →](https://fewvar.github.io/excel-report-merger/)** — перетащить свои
файлы и скачать результат, ничего не устанавливая.

Знакомая задача: в конце месяца на диске лежат двадцать выгрузок — по одной на филиал,
менеджера или неделю. Чтобы посмотреть общую картину, их открывают по очереди и копируют
строки в общий файл. Полчаса ручной работы и почти гарантированная опечатка.

Утилита делает это за секунду.

## Было → стало

**Было** — папка с отдельными файлами:

```
отчёты/
├── продажи-01-январь.xlsx     20 строк
├── продажи-02-февраль.xlsx    20 строк
├── продажи-03-март.xlsx       15 строк
├── продажи-04-апрель.xlsx     19 строк
└── продажи-05-май.xlsx        15 строк
```

**Стало** — один файл с двумя листами:

```
сводный-отчёт.xlsx
├── Данные   89 строк, колонка «Файл-источник», автофильтр, закреплённая шапка
└── Сводка   строк по каждому файлу + суммы и средние по числовым колонкам
```

Лист «Сводка» выглядит так:

```
Источник                  Строк
продажи-01-январь.xlsx       20
продажи-02-февраль.xlsx      20
продажи-03-март.xlsx         15
продажи-04-апрель.xlsx       19
продажи-05-май.xlsx          15
Всего                        89

Числовая колонка          Сумма     Среднее
Количество                  307        3.45
Цена                     676 170     7597.42
Сумма                  2 196 110    24675.39
```

## Что умеет

- Читает `.xlsx`, `.xlsm` и `.csv` — в одной папке можно смешивать форматы.
- **Работает без установленного Microsoft Excel.** Файлы разбираются как формат напрямую,
  поэтому утилита одинаково работает на Windows, macOS и Linux.
- Понимает CSV с разделителем `,`, `;` или табуляцией и кодировки UTF-8 и Windows-1251 —
  определяет сам, ничего указывать не нужно.
- Если в файлах разный набор колонок — объединяет по именам, недостающие ячейки остаются
  пустыми, ни одна колонка не теряется.
- Добавляет колонку «Файл-источник»: всегда видно, откуда пришла строка.
- Считает итоги по числовым колонкам — сумму и среднее.
- Битые и пустые файлы пропускает с объяснением причины и продолжает работу.
- Числа остаются числами, а артикулы вроде `007` не превращаются в `7`.

## Установка

```bash
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

Зависимость одна — `openpyxl`.

## Использование

```bash
python3 merge.py отчёты
```

Результат сохранится в `сводный-отчёт.xlsx` рядом со скриптом.

Параметры:

```
-o, --out ФАЙЛ      куда сохранить результат
-s, --sheet ИМЯ     имя листа в исходных файлах (по умолчанию первый)
-r, --recursive     искать таблицы и во вложенных папках
```

Пример:

```bash
python3 merge.py ~/Документы/выгрузки -o итог-за-квартал.xlsx -r
```

## Попробовать прямо сейчас

В комплекте генератор примеров — можно проверить, не имея своих файлов:

```bash
python3 make_demo.py демо-отчёты
python3 merge.py демо-отчёты
```

Готовый результат такого запуска лежит в [`examples/sample-report.xlsx`](examples/sample-report.xlsx) —
можно скачать и открыть, ничего не устанавливая.

## Как это работает

Колонки собираются в порядке первого файла; те, что встретились только в следующих,
добавляются в конец — так привычный порядок не ломается. Числовой считается колонка,
где числа стоят хотя бы в половине строк: иначе случайная цифра в текстовом поле
превращала бы его в «числовое» и портила итоги.
