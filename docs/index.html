Excel-сборщик отчётов

Папка с десятками однотипных таблиц превращается в один сводный файл с итогами. Перетащите свои файлы или возьмите готовый пример — результат можно скачать сразу.

Файлы никуда не отправляются: всё считается прямо в вашем браузере.

    Что делает утилита

    • Объединяет файлы с разным набором колонок — ничего не теряется, недостающие ячейки остаются пустыми.
    • Добавляет колонку «Файл-источник»: всегда видно, откуда пришла строка.
    • Считает сумму и среднее по числовым колонкам.
    • Понимает CSV с разделителем запятая, точка с запятой или табуляция, в UTF-8 и Windows-1251.
    • Не путает артикулы с числами: 007 останется 007.

    Эта страница — демонстрация. Основной инструмент — консольная утилита на Python, она обрабатывает папки целиком и встраивается в автоматизацию: исходный код на GitHub.
